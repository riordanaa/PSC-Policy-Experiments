# consolidated_report — the claims scorecard (single source of truth up to June 11, 2026)

**`consolidated_findings.pdf`** — one-page claims table with status codes
(established / corrected / open / retracted), the four key findings, a superseded-claims
**do-not-cite** list, and the audit record. Consolidates the routing, understanding, and
value-decomposition/DS-seat studies. **Check this before citing any number from those study
folders** — several folder-level numbers are formally superseded here.

**Scope note:** this scorecard predates the June-22/23 robustness work — the capacity report
(`value_decomposition_study/report/robustness_report.pdf`) and the lead-time/severity report are
NOT indexed here; see `value_decomposition_study/report/README.md` for those.

`consolidated_findings.tex` is the source. `paper_outline.md` sketches the paper structure built
on these findings. `_build/` is local LaTeX output (gitignored).
