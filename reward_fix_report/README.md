# reward_fix_report — repaired-reward experiments (May 2026)

`reward_fix_followup_report.pdf` (+ `.tex` source): what happens with the repaired reward
components (flag-gated in `config.py`, default OFF) — component signal checks, policy-oscillation
analysis, the linear exploration schedule, and a DRL vs base-stock head-to-head. Bottom line: the
repaired agent trains stably but still loses to base stock on system profit. Follow-up to
`reward_report_pdf/`; the RL thread was then paused in favor of the deterministic studies.
